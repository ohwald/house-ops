# ADR-0005: 数据能力画像因市场而异——分析方法必须适配可获取的数据档

日期：2026-11-16 · 状态：已接受

## 背景

不同市场/地区对同一类数据（成交价、挂牌盘口、流动性、宏观指数）的**可获取性、及时性与准确性**差异巨大，且随平台政策随时间变化。实证（2026-11-16，上海，浏览器通道）：

- **链家/贝壳成交页**：成交记录可见（小区/户型/面积/签约日期/中介），但**成交价字段被官方隐藏**（2025-08 起，登录后同样"暂无价格/暂无单价"），且全站 captcha+登录墙——只能当**流动性信号源**（某小区近期有无成交、什么户型在走量）。
- **房天下**：新模板详情页（3_512xxx）带「小区成交记录」块——真实成交价+签约日期逐套可得（三湘实证：439万/124.42㎡/35,364元/㎡，2026-10-25 签约），但**非每页都有**——当前上海的价格锚首选源。
- **房天下参考价（月度）**：估算口径，实测比真实成交**虚高约 17%**（三湘：参考 41,359 vs 成交 35,355）——只作对照，不冒充锚。
- 国家统计局 70 城：月度宏观，及时但聚合。
- 欧洲与亚太市场同样如此（英国 PPD 逐套成交 vs 德国无逐套、新加坡组屋开放 vs 私宅 caveat）——`docs/markets/` 已有登记。

## 决策

1. **数据能力画像是市场的属性**：每个市场按四个维度登记其可获取性——价格粒度（逐套成交 / 估算 / 无）、价格准确性（真实成交 / 估算）、时效（实时 / 月度 / 滞后）、覆盖（全城 / 关注池）。
2. **分析方法必须声明其数据前提**：成交锚（需逐套真实成交）、趋势校准（需历史成交或长时序参考）、流动性信号（需成交记录或带看数据）、趋势指数（需盘口快照）。市场数据能力不足时，该方法在该市场**降级或禁用**，并在输出中明示（如"本市场无逐套成交价，成交锚不可用，改用估算参照"）——绝不跨档冒充。
3. **平台能力变化按实证更新**：数据源的实际可得性以本会话实采为准（ADR-0002），平台政策变化（如上海隐藏成交价、fang 新模板出现成交块）即时更新对应市场的画像与 scan 策略，不依赖过期结论。
4. 中国市场的实例画像见本 ADR 背景节与 `modes/scan.md` Step 3；欧洲/亚太见 `docs/markets/`。

## 后果

- 上海实例：成交锚源 = 房天下成交块（浏览器通道，出现频率不定）；链家成交页降级为流动性信号源；fang 参考价只作对照（虚高 ~17%）。
- scan 的成交锚策略、trend 的校准预期、negotiate 的价格话术都按市场画像适配；跨市场移植方法前先核对画像。
- 报告与协商话术引用任何"市场价"时必须带数据档与 as_of（ADR-0002 纪律的延伸）。
- 市场画像的登记位置：`docs/markets/<market>.md`（叙述）+ `templates/official-sources.*.yml`（tier 字段）+ 平台模块的 `transaction.coverage` 注记。
