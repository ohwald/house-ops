# ADR-0003: 趋势指数聚合封顶关注池——不输出城市级大盘

日期：2026-10-25 · 状态：已接受

## 背景

价格推测体系（盘口边际指数，方法参考"趋势动物 Pro"公开访谈，2026-10-25 调研）需要决定指数的聚合上限。参照产品有全国/城市/板块/组合四级指数；但我们的数据采样是**用户关注小区**（基线约 15-20 个小区的盘口快照），不是市场普查。

## 决策

1. 指数聚合最高到**关注池级**（用户自选组合，类比参照产品的"上海组合"）；
2. 板块级仅当同板块 ≥3 个有指数的小区时输出；
3. **城市级/全国级永不输出**——未来采样扩大（如板块全量基线扫）也不自动升格，升格需新 ADR；
4. 一切指数输出必须携带样本量（事件数/小区数）与 as_of。

## 后果

- 城市大盘读数不在本体系承诺内；用户需要大盘判断时引用政务源（70 城统计等）并标来源，不用自算指数冒充。
- 与 ADR-0002 同源：采样事实决定输出边界，"编得像模像样的大盘"是本仓库最防范的幻觉形态。
- 关注池随 watchlist 演化自然增减，指数含义是"我关注的市场"，不是"市场"。
