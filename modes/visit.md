# Mode: visit — 带看准备与复盘记录

触发：`/house-ops visit 准备 001`（带看前）或 `/house-ops visit 记录 001`（带看后）。带看是信息可靠度的最大升级机会——把"未核实"变成"已核实"。对应 career-ops 的 interview-prep。

前置阅读：`_profile.md`（衍生需求）、该房源报告（含待核实清单）、negotiate 的 Block E（现场核查清单）。

## 准备（带看前）

1. **定制带看清单**：合并三路信息生成"本套专属清单"：
   - 报告的待核实清单（unverified_items）与风险项
   - 画像衍生需求现场可验证项（老人动线/噪音实测/采光时段/学校步行实测）
   - negotiate Block E 通用清单（渗漏/水压/楼道/邻里/物业）
   每项标**验证方法**（如"噪音：关窗开窗各站 1 分钟""采光：问清冬季下午 3 点西晒"），按 30-60 分钟带看时长排优先级。
2. **要带的工具**：卷尺（量房间/家具位）、手机测距/分贝计 App、插座检测器（可选）、报告打印件或手机截图。
3. **提醒**：对上门图片与挂牌图差异保持敏感；重要承诺（学区/家具留存）当场记下，回头写进合同才有约束力。

## 记录（带看后）

1. **落盘** `data/notes/{NNN}-visit-{YYYY-MM-DD}.md`：

```markdown
# 带看记录：001 ××小区 {日期}
- 到场人 / 中介 / 时长 / 天气（影响采光判断）
## 现场核查结果   ← 对照定制清单逐项：✅核实通过 / ⚠️新发现问题 / ➖未验到
## 与评估报告的差异  ← 新发现的减分项/加分项，注明影响哪个维度
## 房东/中介当场合你说的话  ← 原话记录 + 可靠度（中介口述）
## 现场感受  ← 用户主观印象（采光/气味/安静度/邻居印象），标"主观"
## 下一步  ← 约二看 / 进入谈判 / 弃购候选
```

2. **更新 watchlist**：备注追加一行"已看房；"与带看要点。
3. **触发增量重评**：现场新信息若可能改变某维分数（如发现渗漏→Risk，实测噪音→Location），提示用户可跑"增量重评"——只修订受影响维度并更新 综合评分，不全套重跑；重评结果在原报告追加 `## 增量重评 {日期}` 节，不覆盖原文。
4. **二看建议**：一次没验到的关键项（如只有白天去过）列成二看清单；傍晚/雨天二看各有价值。

## 边界

- 带看记录里的主观感受与客观核查分开存放，重评只采信客观项。
- 用户口头一句"看过了，还行"也记录：备注"已看房；用户口头反馈：还行（未提供细节）"。
