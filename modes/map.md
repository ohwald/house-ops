# Mode: map — 房源决策地图

触发：`/house-ops map`、"在地图上看"、"房源分布"、"生成地图"。地图不是评分器，是**空间维度的汇总视图**：所有已评估房源按坐标上图，支持决策过滤、通勤圈与画像保存。

优先跑脚本（零 token）：

- `npm run map:serve` — 本地服务（推荐）：每次请求重载最新报告数据，画像保存直接写回 `config/profile.yml`
- `node scripts/map.mjs` — 生成单文件 `data/map.html`（双击即可打开，无需服务）
- 深链：`?house=<报告编号>` 自动定位房源并打开详情卡（dashboard 的 Enter/m 键即此入口）

## 页面交互

- **左侧边栏 = 房源列表主视图**：全部已评估房源按综合评分从高到低罗列，点击列表项或地图 marker 即在右侧打开详情卡
- **排序**：综合评分 / 单价 / 总价 / 面积 / 房龄 / 地段配套（下拉即切）
- **快速过滤**：总价区间、单价区间、面积区间、房龄上限、楼层段（低/中/高多选）、综合评分门槛、决策档位（第一梯队/备选/排除）
- **已排除房源默认隐藏**（一票否决封顶/超预算/用户判定排除）；marker = 楼盘名 + 综合评分（⚠ = 真实性存疑，★ = 第一梯队）
- **对比**：在详情卡点「加入对比」→ 右下悬浮「方案对比 n」按钮 → 点击进入多方案对比浮层（权衡矩阵）
- **工作地通勤圈**：以画像 work_location 为锚点的辐射范围
- **深链**：?house=<编号> 定位房源并自动打开详情卡（dashboard Enter/m 键即此入口）
## 真实性纪律（ADR-0002）

- ⛔ 作废报告**不上图**（数据层默认过滤）
- ⚠️ 存疑房源在 marker 标签、房源列表、详情卡三处带 ⚠ 标记
- 评分以 watchlist 当前口径为准（报告内旧 Machine Summary 分数不作为展示依据）

## 数据

报告 Machine Summary + watchlist 备注/当前评分合并；坐标缓存于 `data/geo-cache.json`（作废小区坐标已清理，不重复缓存）。
